\# 📊 eSIM Analytics Dashboard – MyBestSim



\## 🚀 Overview



This project is a data analytics dashboard built for a technical test at MyBestSim.

It analyzes a catalog of eSIM products from multiple providers using a Python ETL pipeline.



The goal is to extract business insights from raw CSV data and build a clear dashboard for decision-making.



\---



\## 📦 Dataset



\- 18 eSIM providers

\- 5056 products analyzed

\- Multiple CSV files aggregated



\---



\## 📊 Key Metrics



\- Total products: 5056

\- Price range: 5.36 € → 154.63 €

\- Average price: 29.30 €

\- Average data: 14.5 GB

\- Products > 100€: 56

\- Unlimited offers: 653 (12.9%)



\---



\## 🏆 Insights



\- Majority of products are mid-range (10€–50€)

\- Strong competition between major providers (Airalo, Ubigi, Saily)

\- Best value offers reach \~0.91 €/GB
